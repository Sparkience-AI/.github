# Support

Sparkience repositories are open-source projects with best-effort support.

- Use the repository README for installation and usage guidance.
- Search existing issues before opening a bug report.
- Use the bug form for reproducible defects and the feature form for proposals.
- Include versions, platform, expected behavior, actual behavior, and a minimal safe reproduction.
- Do not post API keys, private datasets, logs containing personal data, or security vulnerabilities.

Support availability depends on the repository's maturity status. Prototype and alpha projects may change quickly and may not receive backports. Security concerns follow [SECURITY.md](SECURITY.md).
