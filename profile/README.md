# Sparkience AI

![Sparkience AI Lab banner](https://raw.githubusercontent.com/Sparkience-AI/.github/main/banner.jpeg)

**A small software lab for working with models, documents and data.**

We like tools that let you see how they work. In SparkDocs, that means being able to find the passage behind an answer. In The Receptionist, it means seeing why a prompt went to the cloud and what it cost. In DSSential, it means putting a forecast next to a simple baseline.

[Try SparkPrompt](https://sparkprompt.streamlit.app/) · [Read Sparkfolio](https://sparkience-ai.github.io/sparkfolio/) · [Browse the source](https://github.com/orgs/Sparkience-AI/repositories)

## The lab bench

### Read, write and work with models

- **[SparkDocs](https://github.com/Sparkience-AI/SparkDocs)** — Ask a question about a PDF, Word document or PowerPoint deck and follow citations back to the source.
- **[SparkPrompt](https://github.com/Sparkience-AI/SparkPrompt)** — Work through a prompt-writing exercise, get feedback on your draft, or start from a template.
- **[SparkOllama](https://github.com/Sparkience-AI/SparkOllama)** — Chat with your local Ollama models in a browser and watch replies stream in.
- **[The Receptionist](https://github.com/Sparkience-AI/receptionist)** — Run developer prompts locally or route them to a cloud model. Every reply shows the route, the reason and the estimated cloud cost.
- **[Sparkle AI](https://github.com/Sparkience-AI/Sparkle-AI)** — Send clipboard text for analysis from a Windows hotkey or the system tray. Automatic capture is a session-only opt-in.

### Work through the numbers

- **[DSSential](https://github.com/Sparkience-AI/DSSential-The-AI-Chief)** — Forecast one time series, compare it with simple baselines and explore what-if scenarios.
- **[Spark Insights](https://github.com/Sparkience-AI/spark-insights)** — Profile a CSV or Excel file, run a regression or classification baseline, and export a reproducible report.
- **[Sparkfolio](https://github.com/Sparkience-AI/sparkfolio)** — An investing and financial-readiness guide for readers in India, with worked examples and source notes. The readiness check runs in your browser.

## Run it on your machine

Start with the setup steps in the project README. Hosted links are demos where available. Tools with cloud model support accept your own Gemini, OpenAI or Anthropic API key. Each project documents what it sends to the provider. Sparkfolio runs without a model or an account, and DSSential and Spark Insights compute results independently of optional AI summaries.
